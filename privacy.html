Privacy Policy

Last updated: 2026-10-14

wsl_driven is a personal tool used only by its developer (Mayank Manas) to access the developer's own Google Drive through rclone.

Data accessed

The app accesses Google Drive files in the developer's own account, solely to sync and back them up.

Data storage and sharing

No data is sent to any server operated by the developer or any third party. OAuth tokens are stored only in the rclone configuration on the developer's own computer. Data is never sold, shared, or used for advertising.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
